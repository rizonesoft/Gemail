Gemail redesign · Direction A

Fluent Native

Gemail as a quiet, first-class citizen of new Outlook.

Rationale

Gemail lives inside Outlook's chrome, so the strongest move is to look like it belongs there. This direction adopts Fluent 2 metrics outright: the communication blue, 4 px and 8 px radii, Segoe UI Variable on Fluent's type ramp, and Outlook's own neutral greys, so the pane reads as part of the client rather than a website in a sidebar. The app icon drops the envelope (which drifts toward other mail brands) for a written letter whose folded corner carries the AI spark: it says "a letter, written with help" and stays readable at 16 px. Purple stays reserved for AI.

What changes versus the approved mockup

  • The primary action moves to a sticky action bar at the bottom of the pane, so Write reply and Insert are always reachable without scrolling.
  • Tone, length and language collapse into one row of three dropdown chips under the instruction; the segmented control and two selects go.
  • After writing, the form folds into an editable instruction summary and the result takes the space; the action bar switches to Reply, Reply all and Copy.
  • Tabs keep the five slots with Fluent's 2 px indicator; Settings stays a header button.
  • Settings becomes grouped Fluent cards with a sticky Save bar instead of a long uncarded list.
  • Ribbon and menu icons share one document base with a single coloured badge each, so the AI Tools family reads as a set.
